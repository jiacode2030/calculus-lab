Series, geometric series & the nth-term test

Can you add infinitely many numbers and get a finite answer? Sometimes yes: it depends on whether the terms shrink fast enough.

The idea

An infinite series Σ aₙ is the limit of its partial sums S_N = a₁ + … + a_N. If S_N approaches a number S, the series converges to S; otherwise it diverges. Think of walking toward a wall: half the distance, then half of what remains, and so on. The steps add up to the whole distance: 1/2 + 1/4 + 1/8 + … = 1.

The geometric series Σ a rⁿ is the model: it converges exactly when |r| < 1, and then the sum from n = 0 is a/(1 − r) (first term over one minus the ratio). The nth-term test is a quick check for divergence: if aₙ does not go to 0, the series diverges. (The converse is false: 1/n → 0 yet Σ 1/n diverges.)

Try this

Predict what will happen first. Then set it up and check.

  1. Set r = 0.5, a = 2. What do the partial sums approach?

    What you should see

    Toward 2/(1 − 0.5) = 4. After 30 terms the sum is within about 10⁻⁸ of it.

  2. Set r = −0.8. What happens, and what about r = 1.2?

    What you should see

    With r = −0.8 the sums zigzag toward a/(1 + 0.8) = 1.11 (converges, |r| < 1). With r = 1.2 the terms grow, so the sums run away: diverges.

Worked example

Find 3 + 1 + 1/3 + 1/9 + …, and decide about Σ n/(n + 1).

Try it yourself first, then reveal one step at a time.

  1. Identify. First term a = 3, ratio r = 1/3: geometric.
  2. Check |r| < 1. 1/3 is between −1 and 1, so it converges.
  3. Sum. a/(1 − r) = 3/(1 − 1/3) = 3/(2/3) = 9/2.
  4. The other series. aₙ = n/(n + 1) → 1 ≠ 0, so by the nth-term test Σ n/(n + 1) diverges.
  5. Answer. The geometric series converges to 9/2; the second one diverges.

Common mistakes

  • Using a/(1 − r) when |r| ≥ 1.
  • Starting at the wrong n: a/(1 − r) assumes the first term is a (starting n = 0). For Σ from n = 1 use a₁/(1 − r).
  • Concluding a series converges because aₙ → 0 (the nth-term test can only prove divergence).
  • Confusing the sequence aₙ with the series Σ aₙ.
  • Forgetting that r is the ratio of consecutive terms.

Repeating decimals

A repeating decimal is a geometric series: 0.777… = 7/10 + 7/100 + … = (7/10)/(1 − 1/10) = 7/9. And 0.2323… = 23/99.
