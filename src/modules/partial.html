Partial fractions & long division

A fraction of polynomials can be split into simpler fractions you can integrate with logarithms.

The idea

A rational function like (3x + 1)/((x − 1)(x + 2)) is hard to integrate, but it is the sum of two simple fractions, A/(x − 1) + B/(x + 2), each integrating to a logarithm. To find A and B, clear the denominators and match: use convenient x-values (the roots of the denominator), or compare coefficients.

First check the degrees. If the top has degree ≥ the bottom, do long division first (a polynomial plus a proper fraction). For repeated or irreducible factors the pieces are A/(x − a) + B/(x − a)² and (Cx + D)/(quadratic); the AP course sticks mostly to distinct linear factors. Also useful here: completing the square for ∫ 1/(x² + bx + c) gives an arctangent.

Try this

Predict what will happen first. Then set it up and check.

  1. Use the default values. What do A and B equal, and what is the check?

    What you should see

    (3x + 1)/((x + 1)(x − 2)) = A/(x + 1) + B/(x − 2) with A = (3(−1) + 1)/(−1 − 2) = 2/3 and B = (6 + 1)/(2 + 1) = 7/3. The two sides agree at every probe x.

  2. Change the probe x. Does the equality ever fail?

    What you should see

    No: it is an identity, true for every x except the roots a and b where the original is not defined.

  3. Set a = −1, b = 1, p = 5, q = 1. What are A and B?

    What you should see

    A = (5(−1) + 1)/(−1 − 1) = 2 and B = (5 + 1)/(1 + 1) = 3. Check at x = 3: the fraction is 16/(4·2) = 2, and 2/4 + 3/2 = 2.

  4. Set a = −1, b = 2, p = 0, q = 3. Why is A negative?

    What you should see

    A = 3/(−1 − 2) = −1 and B = 3/(2 + 1) = 1, so 3/((x + 1)(x − 2)) = −1/(x + 1) + 1/(x − 2). The cover-up divides by (a − b), which is negative here. Check at x = 3: 3/4 = −1/4 + 1.

Worked example

Find ∫ (3x + 1)/((x + 1)(x − 2)) dx.

Try it yourself first, then reveal one step at a time.

  1. Decompose. (3x + 1)/((x + 1)(x − 2)) = A/(x + 1) + B/(x − 2).
  2. Clear denominators. 3x + 1 = A(x − 2) + B(x + 1).
  3. Cover-up. x = 2: 7 = 3B, so B = 7/3. x = −1: −2 = −3A, so A = 2/3.
  4. Integrate each piece. ∫ [ (2/3)/(x + 1) + (7/3)/(x − 2) ] dx.
  5. Answer. (2/3) ln|x + 1| + (7/3) ln|x − 2| + C.

Common mistakes

  • Forgetting long division when the top has degree ≥ the bottom.
  • Mixing up A and B when substituting the roots.
  • Dropping the absolute value in ln|x − a|.
  • Using partial fractions on ∫ 1/(x² + 1), which is arctan.
  • Splitting a sum in the denominator: 1/(x + y) ≠ 1/x + 1/y.

Long division

If the degree of the numerator is at least the degree of the denominator, divide first. For example (x² + 3x + 5)/(x + 1) = x + 2 + 3/(x + 1), and the integral is x²/2 + 2x + 3 ln|x + 1| + C.
