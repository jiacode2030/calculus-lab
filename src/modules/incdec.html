Increasing, decreasing & the first derivative test

Where the slope is positive the function climbs, where it is negative the function falls. The turning points are where the sign changes.

The idea

If f′(x) > 0 on an interval, f is increasing there; if f′(x) < 0, f is decreasing. A critical point is an x in the domain where f′ = 0 or f′ does not exist. These are the only places a function can turn.

First derivative test: at a critical point c, look at the sign of f′ on each side. If f′ changes from + to −, f has a local maximum at c. From − to +: a local minimum. If the sign does not change, c is neither (think x³ at 0). Always justify with a sign chart.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose x³ and slide through 0. Is x = 0 a max, a min or neither?

    What you should see

    Neither: f′ = 3x² is 0 at x = 0 but positive on both sides, so f keeps increasing. A critical point is a candidate, not a guarantee.

  2. Choose x^(2/3). What happens at x = 0?

    What you should see

    f′ does not exist at 0 (a cusp), so 0 is a critical point. f′ changes from − to +, so it is a local minimum.

  3. Choose x³ − 3x with x = 0. Is f increasing or decreasing there, and how steeply?

    What you should see

    Decreasing, with slope f′(0) = −3. The point sits in the middle of (−1, 1), where f′ = 3x² − 3 is negative, so the tangent slopes down.

  4. Choose x⁴ − 2x². How many critical points are there, and which is the local maximum?

    What you should see

    Three: f′ = 4x(x − 1)(x + 1) is 0 at −1, 0 and 1. The sign chart is − + − +, so x = ±1 are local minima (f = −1) and x = 0 is the local maximum (f = 0).

  5. Choose x·e⁻ˣ and slide x through 1. What is f(1), and why can f′ only change sign there?

    What you should see

    f(1) = 1/e ≈ 0.368, a local maximum. f′ = (1 − x)e⁻ˣ and e⁻ˣ is never 0, so the sign of f′ is the sign of 1 − x: positive before 1, negative after.

Worked example

Find the intervals where f(x) = x³ − 3x is increasing or decreasing, and classify its critical points.

Try it yourself first, then reveal one step at a time.

  1. Differentiate. f′(x) = 3x² − 3 = 3(x − 1)(x + 1).
  2. Critical points. f′ = 0 at x = −1 and x = 1.
  3. Sign chart. x < −1: f′ > 0; −1 < x < 1: f′ < 0; x > 1: f′ > 0.
  4. Conclude. f is increasing on (−∞, −1) and (1, ∞), decreasing on (−1, 1).
  5. Classify. At x = −1 the sign goes + → −: local maximum f(−1) = 2. At x = 1 it goes − → +: local minimum f(1) = −2.

Common mistakes

  • Calling any point with f′ = 0 an extremum. Check the sign change.
  • Forgetting critical points where f′ does not exist.
  • Not showing a sign chart or a justification (the exam requires one).
  • Mixing up f and f′: the graph of f′ being above the axis means f is increasing, not that f is positive.
  • Reporting x when asked for the extreme value (the y-value), or the reverse.

Writing the justification

A complete answer says: "f′(x) changes from positive to negative at x = c, so f has a relative maximum at x = c." Always name the function whose sign you are using, and the interval you checked.
