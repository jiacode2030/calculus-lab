Vector-valued functions & motion

A particle moving in the plane has a position vector, a velocity vector and an acceleration vector. Each is the derivative of the one before.

The idea

Write the position as r(t) = ⟨x(t), y(t)⟩. Then the velocity is v(t) = ⟨x′(t), y′(t)⟩ (tangent to the path) and the acceleration is a(t) = ⟨x″(t), y″(t)⟩. The speed is |v| = √(x′² + y′²), and the distance traveled from t = a to t = b is ∫ |v| dt.

Integrate component by component to go backwards: position = initial position + ∫ velocity. The particle speeds up when the acceleration has a positive component along the velocity (v · a > 0) and slows down when v · a < 0. Uniform circular motion has constant speed but nonzero acceleration (pointing to the center): the velocity direction keeps changing.

Try this

Predict what will happen first. Then set it up and check.

  1. On circle motion, compare the speed at different t. Is it constant? What about acceleration?

    What you should see

    The speed is constant (2), but the acceleration is not zero and points to the center: the particle is always turning. Velocity changes direction even when speed does not.

  2. On the projectile, find when the acceleration changes.

    What you should see

    It never changes: a = ⟨0, −2⟩ at every t (gravity). The vertical velocity decreases, then the particle falls.

  3. On the projectile, set t = 2. Compare v and a here. Is the particle speeding up?

    What you should see

    At the top of the path v = ⟨2, 0⟩ and a = ⟨0, −2⟩, so v · a = 0: the velocity is horizontal and the acceleration vertical. The speed is 2, its smallest value on this path, and it is neither increasing nor decreasing at that instant.

  4. Choose the spiral and set t = 3. Is the particle speeding up or slowing down?

    What you should see

    Speeding up: v · a ≈ 3.0 > 0. The speed is √(1 + t²) = √10 ≈ 3.16 and it keeps growing, even though the path keeps turning. The acceleration has a part along the velocity and a part across it.

Worked example

A particle has r(t) = ⟨t², t³ − 3t⟩. Find its velocity, speed and acceleration at t = 2.

Try it yourself first, then reveal one step at a time.

  1. Velocity. v(t) = ⟨2t, 3t² − 3⟩, so v(2) = ⟨4, 9⟩.
  2. Speed. |v(2)| = √(16 + 81) = √97 ≈ 9.849.
  3. Acceleration. a(t) = ⟨2, 6t⟩, so a(2) = ⟨2, 12⟩.
  4. Speeding up? v · a = 4(2) + 9(12) = 116 > 0: yes.
  5. Answer. v = ⟨4, 9⟩, speed √97, a = ⟨2, 12⟩; speeding up.

Common mistakes

  • Forgetting that speed is a magnitude (square root of the sum of squares).
  • Saying the particle is not accelerating because its speed is constant.
  • Differentiating only x or only y: both components.
  • Using the position vector for velocity.
  • Confusing the path (a curve) with the position function (a point moving on it).

Components

Everything works component by component. The x and y motions are independent in a projectile: constant horizontal velocity, constant downward acceleration. For uniform circular motion r(t) = ⟨R cos ωt, R sin ωt⟩, the speed is Rω and the acceleration has size Rω², directed inward.
