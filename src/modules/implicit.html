Implicit differentiation

Some curves, like a circle, cannot be written as y = f(x). You can still find their slopes by differentiating both sides and treating y as a function of x.

The idea

The circle x² + y² = 25 is not a single function (each x has two y values), but near any point it behaves like one. Differentiate both sides with respect to x. The key: whenever you differentiate something with y in it, use the chain rule and write dy/dx, because y depends on x.

For the circle: 2x + 2y·dy/dx = 0, so dy/dx = −x/y. The slope depends on both x and y: you need the point. At (3, 4) the slope is −3/4: the tangent heads down to the right, as a circle does in its upper right.

Try this

Predict what will happen first. Then set it up and check.

  1. On the circle, move to x = 3 on the upper branch. What is the slope?

    What you should see

    At x = 2.4 the point is (2.4, 1.8), and dy/dx = −x/y = −2.4/1.8 = −1.33. The tangent falls to the right.

  2. Switch to the lower branch at the same x. What happens to the slope?

    What you should see

    y is now negative, so −x/y is positive: the lower right of a circle slopes up. Same x, opposite slope, because the formula needs y too.

Worked example

Find dy/dx for x² + y² = 25 and the slope at (3, 4). Then find dy/dx for x²y + y³ = 10.

Try it yourself first, then reveal one step at a time.

  1. Differentiate both sides. d/dx[x²] + d/dx[y²] = d/dx[25] gives 2x + 2y·y′ = 0.
  2. Solve for y′. 2y·y′ = −2x, so y′ = −x/y. At (3, 4): −3/4.
  3. Second curve, product rule on x²y. 2xy + x²y′ + 3y²y′ = 0.
  4. Collect the y′ terms. y′(x² + 3y²) = −2xy.
  5. Answer. y′ = −2xy/(x² + 3y²).

Common mistakes

  • Forgetting dy/dx after differentiating a y term: (y²)′ is 2y·y′, not 2y.
  • Not using the product rule on mixed terms like xy.
  • Dropping y from the answer. Leave it in; the formula depends on both coordinates.
  • Not isolating dy/dx: collect every y′ term on one side, factor and divide.
  • Substituting the point too early. Differentiate first, then substitute.

Why it works

Near a point on the curve, y is some function of x, even if you cannot write it down. Differentiating an equation that is true for all nearby (x, y) gives another true equation. The chain rule is just the way to differentiate y² = (y(x))² with respect to x.
