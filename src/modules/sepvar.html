Separation of variables & exponential models

For some equations you can move all the y's to one side and all the x's to the other, then integrate. The most important result: when something changes at a rate proportional to itself, it follows an exponential.

The idea

Separate: for dy/dx = f(x)·g(y), write dy / g(y) = f(x) dx, integrate both sides, and put the constant C on the x side (once). Then use the initial condition to find C, and solve for y if possible. Skipping the +C before using the starting value is the classic error.

The model dy/dt = k y says the rate is proportional to the amount. Separating gives y = y₀ ekt. With k > 0 it is exponential growth (population, money at continuous interest); with k < 0 it is decay (radioactive material, with half-life ln 2 / |k|). Newton's law of cooling, dT/dt = −k(T − Ta), is the same thing for the difference T − Ta.

Try this

Predict what will happen first. Then set it up and check.

  1. Set k = 0.3 and y₀ = 2. When does the quantity double?

    What you should see

    After ln 2 / 0.3 ≈ 2.31 time units, and again after another 2.31. The doubling time does not depend on the starting value.

  2. Switch to cooling with Tₐ = 1, y₀ = 6 and k = 0.4. What does T approach?

    What you should see

    The room temperature, 1: the difference T − Tₐ decays exponentially, so T levels off at Tₐ.

Worked example

Solve dy/dx = 2xy with y(0) = 3.

Try it yourself first, then reveal one step at a time.

  1. Separate. dy/y = 2x dx (valid for y ≠ 0).
  2. Integrate both sides. ln|y| = x² + C.
  3. Solve for y. |y| = eC ex², so y = A ex² with A = ± eC.
  4. Use y(0) = 3. A·e⁰ = 3, so A = 3.
  5. Answer. y = 3ex².

Common mistakes

  • Not separating completely: all y's (with dy) on one side, all x's (with dx) on the other.
  • Forgetting + C, or adding it on both sides.
  • Using the initial condition before including C.
  • Dividing by something that could be zero without noting the equilibrium solution.
  • Mixing up k signs: k < 0 is decay.

Why exponentials

If the rate of change is proportional to the amount, a bigger amount grows faster, which makes it even bigger: that feedback is the shape of ekt. Check any proposed solution by differentiating: if y = y₀ekt then dy/dt = k·y₀ekt = k y. ✓
