Improper integrals

What if the area stretches out forever, or the function blows up inside the interval? Sometimes the area is still finite.

The idea

An integral is improper if one limit is ∞ or the integrand blows up on the interval. Replace the troublesome point by a variable and take a limit: ∫1∞ f dx = limb→∞ ∫1b f dx. If the limit is a number the integral converges to it; if not, it diverges.

The benchmark: ∫1∞ 1/xp dx converges iff p > 1 (to 1/(p − 1)); and ∫01 1/xp dx converges iff p < 1 (to 1/(1 − p)). So 1/x² has finite area from 1 to ∞, but 1/x does not, narrowly.

Try this

Predict what will happen first. Then set it up and check.

  1. Set p = 2 and push the slider out. What does the area approach?

    What you should see

    1: the area from 1 to b is 1 − 1/b → 1. The infinite tail has finite area.

  2. Set p = 1 and push out. Does it level off?

    What you should see

    No: the area is ln b, which grows forever (slowly). ∫ 1/x from 1 to ∞ diverges.

  3. Choose ∫₀¹ 1/xᵖ dx and set p = 0.5. Does it converge near 0?

    What you should see

    Yes, to 1/(1 − p) = 2. A singularity at 0 is tolerable when p < 1: the curve climbs, but slowly enough to keep the area finite. The pattern is the reverse of the one at ∞.

  4. Choose ∫₁^∞ 1/xᵖ dx and set p = 1.5. What does it converge to?

    What you should see

    To 1/(p − 1) = 2. Any p > 1 converges at ∞, and it gets slower to converge as p drops toward 1, where it fails.

  5. Choose ∫₀¹ 1/xᵖ dx and set p = 1. Converge or diverge?

    What you should see

    Diverges: the area from ε to 1 is ln(1/ε), which grows without bound as ε → 0. p = 1 is the borderline for both types of integral.

Worked example

Decide whether ∫1∞ 1/x² dx and ∫1∞ 1/x dx converge, and evaluate any that do.

Try it yourself first, then reveal one step at a time.

  1. Replace ∞ by b. ∫1b x−2 dx = [−1/x]1b = 1 − 1/b.
  2. Take the limit. limb→∞ (1 − 1/b) = 1. Converges to 1.
  3. The other. ∫1b 1/x dx = ln b, and limb→∞ ln b = ∞.
  4. Answer. The first converges to 1; the second diverges.

Common mistakes

  • Plugging ∞ in as a number. Always take a limit of an integral with a variable limit.
  • Forgetting the integrand can be unbounded at an interior point, which also makes it improper.
  • Thinking a tail that gets small must have finite area: 1/x → 0 but its area diverges.
  • Reversing the p-conditions for the two types (p > 1 at ∞; p < 1 at 0).
  • Forgetting to split an integral with a problem point inside.

Comparison

If 0 ≤ f ≤ g and ∫ g converges, then ∫ f converges; if ∫ f diverges, so does ∫ g. This lets you decide convergence without finding the value, and it returns in the series tests.
