Euler's method

When you cannot solve a differential equation, you can still follow its slopes in small steps.

The idea

Start at the initial point (x₀, y₀). The differential equation gives the slope there. Walk along that tangent line for a short step Δx = h, arrive at a new point, find the new slope, and repeat. The rule is yn+1 = yn + h·F(xn, yn) with xn+1 = xn + h.

Smaller steps follow the true curve more closely. Euler's method underestimates when the solution is concave up (it follows tangent lines, which lie below), and overestimates when concave down. It is a numerical approximation of a solution you could trace by hand on a slope field.

Try this

Predict what will happen first. Then set it up and check.

  1. Use h = 1 on dy/dx = y. Is the estimate too high or too low?

    What you should see

    Too low: the exact y = eˣ is concave up, so each tangent line lies below it. With h = 1 the estimate at x = 2 is 4 versus the exact 7.39.

  2. Now shrink h to 0.05. What happens to the error?

    What you should see

    It shrinks a lot: more, shorter steps hug the curve. The error is roughly proportional to h.

  3. Use h = 1 on dy/dx = −2xy, y(0) = 1. What does the estimate at x = 2 look like?

    What you should see

    It is −1, an impossible value: the exact solution e^(−x²) is always positive. The first step uses slope 0 at x = 0, and the second step overshoots badly. A step size that is too large can give nonsense.

  4. Use h = 0.5 on dy/dx = y. Predict the estimate at x = 2 before you look.

    What you should see

    Each step multiplies y by 1 + h = 1.5, and there are 4 steps: 1.5⁴ = 5.0625 (exact 7.389). With h = 1 it was 2² = 4, and with h = 0.05 it is 1.05⁴⁰ ≈ 7.04.

Worked example

Use Euler's method with h = 0.5 to estimate y(1) if dy/dx = x + y and y(0) = 1.

Try it yourself first, then reveal one step at a time.

  1. Step 1 from (0, 1). slope = 0 + 1 = 1, so y₁ = 1 + 0.5(1) = 1.5 at x = 0.5.
  2. Step 2 from (0.5, 1.5). slope = 0.5 + 1.5 = 2, so y₂ = 1.5 + 0.5(2) = 2.5 at x = 1.
  3. Answer. y(1) ≈ 2.5. (The exact solution is 2e − 2 ≈ 3.44: Euler underestimates since y is concave up.)

Common mistakes

  • Using the slope at the old point for the wrong coordinates: use both xn and yn.
  • Forgetting to move x by h each step.
  • Stopping at the wrong number of steps: (xend − x₀)/h steps.
  • Believing Euler is exact. It is only an approximation.
  • Mixing up over- and under-estimates: tangent lines lie below a concave-up curve.

Why it works

Near a point the solution is almost its tangent line, whose slope the differential equation gives exactly. Each step makes a small error; many small steps keep the total error small. The smaller the step, the closer you stay to the true curve.
