Extreme values & the Mean Value Theorem

Two guarantees about continuous and differentiable functions: there is always a highest and lowest point, and somewhere the slope equals the average slope.

The idea

Extreme Value Theorem: a function continuous on a closed interval [a, b] has an absolute maximum and an absolute minimum there. They occur at endpoints or at critical points, where f′ = 0 or f′ does not exist. To find them, evaluate f at the critical points and at both endpoints (the candidates test).

Mean Value Theorem: if f is continuous on [a, b] and differentiable on (a, b), then somewhere inside there is a point c where the tangent line is parallel to the secant line: f′(c) = (f(b) − f(a))/(b − a). If you drove 120 miles in 2 hours, at some moment your speedometer read exactly 60.

Try this

Predict what will happen first. Then set it up and check.

  1. On x³/3 − x with the default interval, find where the tangent is parallel to the secant.

    What you should see

    There can be more than one c. Each orange tangent is parallel to the secant. The MVT only promises at least one.

  2. Choose |x|. Does a tangent parallel to the secant exist?

    What you should see

    No: the slope of |x| is only −1 or 1, but the average slope here is 1/3. The MVT does not apply because |x| is not differentiable at 0, which lies inside the interval.

Worked example

Verify the MVT for f(x) = x² on [1, 3] and find c.

Try it yourself first, then reveal one step at a time.

  1. Check the hypotheses. f is a polynomial: continuous and differentiable everywhere.
  2. Average slope. (f(3) − f(1))/(3 − 1) = (9 − 1)/2 = 4.
  3. Set the derivative equal. f′(c) = 2c = 4.
  4. Solve. c = 2, and 2 lies in (1, 3). ✓
  5. Answer. c = 2. (The tangent at x = 2 has slope 4, parallel to the secant.)

Common mistakes

  • Using the MVT without checking continuity and differentiability.
  • Giving a c outside (a, b).
  • Finding extremes by only looking where f′ = 0 and forgetting the endpoints.
  • Confusing the MVT (an average slope) with Rolle's theorem (the special case f(a) = f(b), slope 0).
  • Saying a local maximum is the absolute maximum. Compare all candidates.

The candidates test

To find absolute extremes of a continuous f on [a, b]: (1) find critical points inside (a, b), (2) evaluate f at each critical point and at a and b, (3) the largest value is the maximum and the smallest is the minimum. It always works on a closed interval; on an open interval an extreme may not exist.
