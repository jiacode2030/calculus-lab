Slope fields

A differential equation tells you the slope at every point. A slope field draws those slopes, and the solutions are the curves that follow them.

The idea

A differential equation like dy/dx = x − y gives the slope of a solution at every point (x, y) without telling you the solution. A slope field draws a tiny line segment of the right slope at a grid of points. A solution curve is one that is tangent to the segments everywhere it passes, like a leaf drifting on a current.

Read the field: if the right side depends only on x, segments in each vertical column are parallel; if only on y, segments in each row are parallel; slopes are zero where the right side is zero. Choose a starting point and you can trace the one solution through it. An initial condition like y(0) = 1 picks that curve.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose dy/dx = x. What do the solutions look like, and why are the segments in each column parallel?

    What you should see

    Parabolas y = x²/2 + C. The slope depends only on x, so every point in a vertical column has the same slope.

  2. Choose dy/dx = y and start at y₀ = 1, then at y₀ = −1. What happens?

    What you should see

    Solutions y = Ce^x grow away from the x-axis in both directions: y = 0 is a solution but an unstable one. Segments are parallel along each row (slope depends only on y).

Worked example

For dy/dx = x − y with y(0) = 1, find the slope at the start and use the tangent line to estimate y(0.2).

Try it yourself first, then reveal one step at a time.

  1. Slope at (0, 1). dy/dx = 0 − 1 = −1.
  2. Tangent line. y ≈ 1 + (−1)(x − 0).
  3. Estimate. y(0.2) ≈ 1 − 0.2 = 0.8.
  4. Answer. About 0.8. (This is one step of Euler's method, a BC topic: use the new point to find a new slope.)

Common mistakes

  • Reading a slope field as the graph of the solution. The segments show slope only.
  • Mixing up "depends only on x" (parallel in columns) with "depends only on y" (parallel in rows).
  • Forgetting that two different solutions never cross (for a smooth equation).
  • Using the slope formula at the wrong point.
  • Believing the field determines one curve. You need an initial condition.

Equilibrium solutions

Where dy/dx = 0 for all x along a horizontal line y = c, that line is a solution (an equilibrium). In dy/dx = y it is y = 0. In the last case of the lab, y = 0 and y = 4 are equilibria, and solutions between them level off at 4.
