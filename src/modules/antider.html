Antiderivatives

An antiderivative undoes a derivative. Because constants vanish when you differentiate, every function has a whole family of antiderivatives.

The idea

F is an antiderivative of f if F′ = f. The antiderivative of 2x is x², but so are x² + 5 and x² − 100: they all have slope 2x. The family is written ∫ f(x) dx = F(x) + C, and C is the constant of integration. Graphically, the antiderivatives are the same curve shifted up and down.

Run your derivative rules backwards. ∫ xn dx = xn+1/(n+1) + C (n ≠ −1), ∫ 1/x dx = ln|x| + C, ∫ ex dx = ex + C, ∫ cos x dx = sin x + C. An initial condition like F(1) = 3 picks out the one curve in the family.

Try this

Predict what will happen first. Then set it up and check.

  1. Change C. What changes about the curve, and what stays the same?

    What you should see

    The curve slides up or down, but the slope at each x is identical: the slope readout does not change with C. That is why C is arbitrary until an initial condition fixes it.

  2. Choose cos x. The slope of the highlighted curve at x = 0.5 matches what?

    What you should see

    cos(0.5) = 0.878: F = sin x + C has slope cos x, so F is an antiderivative of cos x for every C.

Worked example

Find the function F with F′(x) = 6x² − 4x and F(1) = 5.

Try it yourself first, then reveal one step at a time.

  1. Antiderivative. F(x) = 2x³ − 2x² + C.
  2. Apply the condition. F(1) = 2 − 2 + C = C = 5.
  3. Answer. F(x) = 2x³ − 2x² + 5.

Common mistakes

  • Forgetting + C in an indefinite integral.
  • Using the power rule on 1/x: ∫ 1/x dx = ln|x| + C, not x⁰/0.
  • Differentiating instead of integrating: raise the exponent, then divide by the new exponent.
  • Forgetting to divide by the coefficient inside, for example ∫ cos(3x) dx = sin(3x)/3 + C.
  • Using F(a) = b with the wrong sign when solving for C.

Check by differentiating

An antiderivative can always be checked: differentiate your answer; you must get the original integrand back. If it does not match, the integral is wrong. This check catches most mistakes on the exam.
