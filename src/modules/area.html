Area between curves

The region between two curves is made of thin slices. Top minus bottom, added up, gives the area.

The idea

Slice the region into vertical strips. Each has width dx and height (top − bottom), so the area is ∫ab (f(x) − g(x)) dx where f ≥ g. Find the limits by solving f(x) = g(x). If the curves cross, split the integral at each crossing so the height is always top minus bottom (never negative).

Sometimes horizontal slices are easier: width dy and length (right − left), giving ∫cd (xright − xleft) dy. Use them when the region is bounded by curves that are easy to write as x = h(y), or when top/bottom switch.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose √x and x² and slice with n = 8. How close is the sum to the exact area?

    What you should see

    Close, a little off: the sum is a midpoint estimate. The exact area is 1/3. More slices give a better answer.

  2. Choose y = x³ and y = x. Which is on top, and why must you split the integral?

    What you should see

    On (0, 1) the line y = x is on top; on (−1, 0) the cubic is. The curves cross at x = 0, so top and bottom swap there. Splitting (or using symmetry) keeps every height positive.

Worked example

Find the area enclosed by y = x and y = x².

Try it yourself first, then reveal one step at a time.

  1. Intersections. x = x² ⇒ x = 0 or 1.
  2. Top and bottom. On (0, 1), x ≥ x², so top = x, bottom = x².
  3. Integrate. ∫01 (x − x²) dx = [x²/2 − x³/3]01.
  4. Answer. 1/2 − 1/3 = 1/6.

Common mistakes

  • Subtracting in the wrong order, giving a negative area. Use top − bottom.
  • Using the wrong limits: find intersections by setting the functions equal.
  • Not splitting at crossings when top and bottom switch.
  • Integrating x² − x as if it were the area under one curve minus a number.
  • Using dx slices when horizontal slices would avoid splitting.

Vertical or horizontal?

Vertical slices (dx): integrand top − bottom as a function of x. Horizontal slices (dy): integrand right − left as a function of y, so you must write each boundary as x = h(y). Choose the one where the boundary does not change formulas partway through.
