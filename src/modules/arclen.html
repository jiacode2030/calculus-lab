Arc length

How long is a curve? Approximate it with tiny straight pieces and use the Pythagorean theorem on each.

The idea

A tiny piece of the curve over a width dx rises by dy, so its length is √(dx² + dy²) = √(1 + (dy/dx)²) dx. Adding them up: L = ∫ab √(1 + (f′(x))²) dx. The polygon with more and more short segments approaches this length.

The integrand rarely has a nice antiderivative, which is why exam problems are chosen so that 1 + (f′)² is a perfect square, or ask you to evaluate with a calculator. Always differentiate first, then square f′ (not f), and then integrate.

Try this

Predict what will happen first. Then set it up and check.

  1. Set n = 1 on y = x². How does the one-chord length compare with the arc length?

    What you should see

    A straight chord is always shorter than the curve through the same end points. Chord: √(4 + 16) = 4.47; the curve is 4.65.

  2. Increase n to 40. What happens?

    What you should see

    The polygon length climbs toward the integral from below. The integral is the limit of polygon lengths as the pieces shrink.

  3. Choose y = sin x on [0, π] and set n = 1, then n = 4. What do the lengths do?

    What you should see

    One chord is the base π ≈ 3.142, and four chords give 3.790; the arc length is about 3.820. The polygon always stays below the curve and climbs toward the integral as n grows.

  4. Choose y = (2/3)x^(3/2) and set n = 3. How close is the polygon?

    What you should see

    Polygon 4.647 against the exact 14/3 ≈ 4.667: about 0.4% short with only 3 chords, because this curve is almost straight. The sine curve with 4 chords is about 0.8% short.

Worked example

Find the length of y = (2/3)x3/2 from x = 0 to x = 3.

Try it yourself first, then reveal one step at a time.

  1. Derivative first. f′(x) = x1/2, so (f′)² = x.
  2. Set up. L = ∫03 √(1 + x) dx.
  3. Integrate. (2/3)(1 + x)3/2 from 0 to 3 = (2/3)(8 − 1).
  4. Answer. 14/3 ≈ 4.667.

Common mistakes

  • Squaring f instead of f′ in 1 + (f′)².
  • Forgetting the square root or the 1.
  • Leaving the derivative inside √ without squaring: it is (f′)², not f′.
  • Using the area formula by mistake.
  • Not simplifying: look for 1 + (f′)² as a perfect square.

Parametric arc length

If x = x(t) and y = y(t), the length is ∫ √((dx/dt)² + (dy/dt)²) dt. The speed of a particle is the same square root, so arc length is the integral of speed.
