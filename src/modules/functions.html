Functions & transformations

Before derivatives: how to read a formula as a graph. Shift, stretch and flip a parent function and see exactly what each number does.

The idea

Every graph in calculus is a familiar parent function that has been moved. y = a·f(b(x − h)) + k says: shift right by h, shift up by k, stretch vertically by a (flip if negative) and squeeze horizontally by b. Changes inside the parentheses act on x and act backwards (x − h moves right); changes outside act on y and do what they say.

Functions can also be composed, f(g(x)) (do g first), and many have inverses that reflect the graph over the line y = x. Composition is what the chain rule differentiates.

Try this

Predict what will happen first. Then set it up and check.

  1. Set h = 2 and k = 1 on x². Where is the vertex?

    What you should see

    At (2, 1): right 2 because of (x − 2), up 1 because of + 1.

  2. Set a = −1 on x². What happens?

    What you should see

    The parabola flips upside down: a negative a reflects the graph across the x-axis.

  3. Choose sin x and set b = 2. How does the graph change?

    What you should see

    It repeats twice as fast: the period is 2π/2 = π instead of 2π. A larger b squeezes the graph horizontally toward the y-axis, while its height stays 1.

  4. Choose |x| with a = −2 and k = 3. Where is the corner, and which way does it open?

    What you should see

    The corner moves to (0, 3), and the graph opens downward: a = −2 flips it over and also makes it steeper (slopes ±2). The equation is y = −2|x| + 3.

  5. Choose √x and set h = −2. Where does the graph start? Which way did it move?

    What you should see

    It starts at (−2, 0): the equation is √(x + 2), and + 2 inside moves the graph LEFT by 2. Inside changes act backwards, which is why x + 2 is a move to the left.

Worked example

If f(x) = x² + 1 and g(x) = 2x − 3, find f(g(2)) and g(f(2)).

Try it yourself first, then reveal one step at a time.

  1. Inside first. For f(g(2)) work out g(2) = 2·2 − 3 = 1.
  2. Then f. f(1) = 1² + 1 = 2.
  3. Now the other order. f(2) = 4 + 1 = 5, then g(5) = 10 − 3 = 7.
  4. Answer. f(g(2)) = 2 and g(f(2)) = 7. Composition is not commutative.

Common mistakes

  • Moving the wrong way: (x + 2) shifts the graph left, not right.
  • Applying h before the stretch b when b is inside: in y = f(b(x − h)) the shift is h, not h/b.
  • Mixing up f(g(x)) and g(f(x)).
  • Treating f−1(x) as 1/f(x). It is the inverse function, not the reciprocal.

Even, odd and inverses

Even functions satisfy f(−x) = f(x) (mirror in the y-axis, like x²). Odd functions satisfy f(−x) = −f(x) (turn 180° about the origin, like x³ and sin x). A function has an inverse only if it passes the horizontal line test; the inverse graph is the reflection over y = x.
