Comparison & ratio tests

Decide whether a series converges without finding its sum: compare it with one you know, or look at how fast the terms shrink.

The idea

Direct comparison: if 0 ≤ aₙ ≤ bₙ and Σ bₙ converges, then Σ aₙ converges; if aₙ ≥ bₙ ≥ 0 and Σ bₙ diverges, so does Σ aₙ. Limit comparison: if aₙ/bₙ → L with 0 < L < ∞, both series do the same thing. Pick bₙ by keeping only the dominant terms: (n + 1)/(n³ + 5) behaves like 1/n².

Ratio test: let L = lim |aₙ₊₁/aₙ|. If L < 1 the series converges absolutely; if L > 1 it diverges; if L = 1 the test says nothing. It shines with factorials and exponentials (n!, 2ⁿ) and is useless for p-series (L = 1).

Try this

Predict what will happen first. Then set it up and check.

  1. Choose 2ⁿ/n!. What does the ratio do as n grows?

    What you should see

    The ratio is 2/(n + 1), which goes to 0, so L = 0 < 1: converges absolutely. Factorials grow faster than exponentials.

  2. Choose 1/n². What is L, and does the test decide?

    What you should see

    L = 1, so the ratio test is inconclusive. (1/n² converges, 1/n diverges, and both have L = 1.) Use the p-series test instead.

Worked example

Decide whether Σ n/3ⁿ and Σ (n + 1)/(n³ + 5) converge.

Try it yourself first, then reveal one step at a time.

  1. First series: ratio test. |aₙ₊₁/aₙ| = [(n + 1)/3ⁿ⁺¹]·[3ⁿ/n] = (n + 1)/(3n) → 1/3.
  2. Conclude. L = 1/3 < 1, so it converges.
  3. Second series: limit comparison with 1/n². aₙ/bₙ = n²(n + 1)/(n³ + 5) → 1.
  4. Conclude. 0 < 1 < ∞ and Σ 1/n² converges, so it converges.
  5. Answer. Both converge.

Common mistakes

  • Using the ratio test on a p-series (L = 1 always).
  • Concluding "diverges" when L = 1. The test is inconclusive.
  • Comparing in the wrong direction: a series smaller than a divergent one proves nothing.
  • Applying direct comparison without positive terms.
  • Choosing bₙ that does not capture the dominant behavior.

Choosing the test

Factorials or exponentials in aₙ: ratio test. Rational function of n (or roots): limit comparison with a p-series. Terms like 1/(n² + 1) that are slightly smaller than 1/n²: direct comparison. If the terms alternate in sign: the next module.
