Continuity & the IVT

A function is continuous if you can draw it without lifting your pencil. Calculus needs a sharper test, and one big consequence: continuous functions cannot skip values.

The idea

Continuity at a point means three things hold: f(a) exists, the limit as x → a exists, and they are equal. A hole, a jump or a blow-up each breaks one of the three. Continuous on an interval means continuous at every point of it.

If a function is continuous on [a, b] it cannot skip over any value between f(a) and f(b). That is the Intermediate Value Theorem. It is why you can say a root exists in an interval without finding it.

Try this

Predict what will happen first. Then set it up and check.

  1. Slide k to 3. What changes in the three-part checklist?

    What you should see

    At k = 3 the right piece starts at 3·2 − 3 = 3, exactly where the left piece is heading (2 + 1 = 3). All three conditions pass: f(2) = 3, the limit is 3, and they match.

  2. Tick Break the function and set N = 2. Does any x give f(x) = 2?

    What you should see

    No. The jump skips from height 0.25 to 3.25, so heights in between are never reached. The IVT does not apply because the function is not continuous.

  3. Slide k to 1. How big is the jump?

    What you should see

    The left piece heads to 3, but at k = 1 the right piece starts at 2(1) − 3 = −1. The jump is 3 − (−1) = 4, and the verdict says discontinuous. Only k = 3 repairs it.

  4. Leave the function unbroken and set N = 3. Where does f(x) = 3, and why is it guaranteed?

    What you should see

    x² − 2 = 3 gives x = √5 ≈ 2.236. The function is continuous on [0, 3] with f(0) = −2 and f(3) = 7, and 3 is between them, so the IVT promises a solution.

  5. Tick Break the function and set N = 0. Is a crossing still found? Why does the break not matter here?

    What you should see

    Yes: x = √2 ≈ 1.414, which is left of the jump at 1.5. The break only hides the heights between 0.25 and 3.25. The IVT does not apply, but a crossing can still exist.

Worked example

Find k so that f(x) = x² for x ≤ 1 and f(x) = kx + 2 for x > 1 is continuous at x = 1.

Try it yourself first, then reveal one step at a time.

  1. Left piece at 1. f(1) = 1² = 1, and the left limit is also 1.
  2. Right limit. As x → 1⁺ the function is kx + 2, so the right limit is k + 2.
  3. Match. Continuity needs left = right = f(1): k + 2 = 1.
  4. Solve. k = −1.

Common mistakes

  • Checking only that the limit exists and forgetting f(a) must be defined and equal to it.
  • Calling a hole a "jump". A hole (removable) has matching sides; a jump does not.
  • Using the IVT without checking the function is continuous on the whole closed interval.
  • Thinking the IVT finds the number: it only guarantees one exists.
  • Assuming "continuous" means "differentiable". A corner is continuous but not differentiable (Unit 2).

Types of discontinuity

Removable: the limit exists but f(a) is missing or different. Jump: the one-sided limits are different numbers. Infinite: the function blows up (a vertical asymptote). Oscillating: the function swings forever. A removable discontinuity can be "repaired" by redefining f(a) as the limit.
