Alternating series & error bounds

Terms that alternate in sign can converge even when the unsigned series does not, and you get a neat built-in error bound.

The idea

An alternating series Σ (−1)ⁿ⁺¹ bₙ (with bₙ > 0) converges if the terms decrease (bₙ₊₁ ≤ bₙ) and go to 0. That is the alternating series test. The partial sums swing back and forth, each overshooting the true sum less than before.

That gives the alternating series error bound: stopping after N terms, the error is at most the first omitted term, |S − S_N| ≤ b_{N+1}, and the true sum lies between S_N and S_{N+1}. Then separate the cases: Σ|aₙ| converges ⇒ absolutely convergent (and so convergent). If Σ aₙ converges but Σ|aₙ| diverges, it is conditionally convergent: the alternating harmonic series 1 − 1/2 + 1/3 − … is the classic example.

Try this

Predict what will happen first. Then set it up and check.

  1. Set p = 1 (alternating harmonic series), N = 8. Where is the true sum, and how far off is S₈?

    What you should see

    The sum is ln 2 ≈ 0.693. S₈ ≈ 0.635, and the bound is 1/9 ≈ 0.111; the real error is 0.058, within the bound.

  2. Set p = 0.5 and then 2. What changes about the type of convergence?

    What you should see

    For 0 < p ≤ 1 it converges only because of the alternating signs (conditional). For p > 1 even the absolute values converge (absolute convergence).

  3. Set p = 2 and N = 10. How good is S₁₀, and what is the bound?

    What you should see

    S10 ≈ 0.8180 and the bound is b11 = 1/121 ≈ 0.0083. The true sum is π²/12 ≈ 0.8225, so the real error is about 0.0045, within the bound.

  4. Set p = 0.3 and N = 30. Is the error bound useful here?

    What you should see

    The series still converges (conditionally), but b31 = 31−0.3 ≈ 0.357, almost as large as the partial sum 0.386. The bound is correct but nearly useless: terms that shrink slowly need many terms.

  5. Set p = 1 and slide N from 8 to 9. Which side of the sum is SN on for odd N and for even N?

    What you should see

    For odd N the partial sum is above the true sum ln 2 ≈ 0.693 (the last term added was positive), and for even N it is below. The true sum always lies between consecutive partial sums.

Worked example

How many terms of Σ (−1)ⁿ⁺¹/n² guarantee an error less than 0.01? Is the series absolutely convergent?

Try it yourself first, then reveal one step at a time.

  1. Check the test. bₙ = 1/n² is decreasing and → 0, so the series converges.
  2. Error bound. |S − S_N| ≤ b_{N+1} = 1/(N + 1)².
  3. Require less than 0.01. 1/(N + 1)² < 0.01 ⇒ (N + 1)² > 100 ⇒ N + 1 > 10 ⇒ N ≥ 10.
  4. Absolute? Σ 1/n² is a convergent p-series (p = 2), so the series converges absolutely.
  5. Answer. N = 10 terms; absolutely convergent.

Common mistakes

  • Skipping the decreasing condition in the alternating series test.
  • Using b_N instead of b_{N+1} for the error bound.
  • Thinking every convergent alternating series converges absolutely.
  • Applying the error bound to a non-alternating series.
  • Counting the number of terms off by one: S_N has N terms and the bound is the (N + 1)th term.

Absolute vs conditional

Absolute convergence is the strongest kind: rearranging terms cannot change the sum. A conditionally convergent series like 1 − 1/2 + 1/3 − … is fragile: its terms can be rearranged to sum to any number (Riemann). In the course, you need to classify a series as absolutely convergent, conditionally convergent or divergent.
