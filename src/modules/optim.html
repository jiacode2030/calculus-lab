Optimization

Biggest area, least material, fastest time: set up a formula for the quantity, find where its derivative is zero, and check it is the best.

The idea

An optimization problem has four steps. Draw and name the variables. Write the objective (the thing to maximize or minimize) and a constraint (what is fixed). Use the constraint to write the objective in one variable. Then differentiate, set to zero, solve, and justify that you have a max or min (first or second derivative test, or the candidates test on a closed interval).

Do not forget the domain: dimensions are positive, and endpoints can be the answer. In the lab the picture and the graph move together: the best value sits at a peak or valley of the graph, where the orange tangent is flat.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose the fence problem. Slide x to find the largest area.

    What you should see

    The maximum area is 1250 ft² at x = 25 (so the other side is 50). The derivative A′ = 100 − 4x is zero there and changes from + to −.

  2. Choose the open box. What size square cut gives the largest volume?

    What you should see

    x = 2 gives V = 2(12 − 4)² = 128 cm³, the maximum for a 12 cm sheet. Any larger cut leaves too little base; any smaller one makes the box too shallow.

  3. Choose the can and find the radius with the least metal. Compare its height with its width.

    What you should see

    r ≈ 3.84 cm and h ≈ 7.67 cm, so the height equals the diameter. That is true for every volume: setting S′ = 0 gives r³ = V/(2π), and then h = V/(πr²) = 2r.

  4. Back to the fence. Change the fixed amount of fencing to 200 ft and find the best x again. Then try 60 ft.

    What you should see

    The best x is 50 for 200 ft and 15 for 60 ft: always P/4, with the long side P/2. The constraint changes the numbers but not the shape of the answer.

  5. Choose the box and make the sheet 30 cm wide. Where is the best cut now?

    What you should see

    x = 5 = 30/6, giving V = 5·20² = 2000 cm³. For any a × a sheet the best cut is a/6, because V′ = (a − 2x)(a − 6x).

Worked example

100 ft of fence encloses a rectangular pen against a straight river (no fence on the river side). Find the dimensions of the largest area.

Try it yourself first, then reveal one step at a time.

  1. Variables. Let x = the two sides perpendicular to the river, y = the side parallel. Constraint: 2x + y = 100, so y = 100 − 2x.
  2. Objective. A = x·y = x(100 − 2x) = 100x − 2x², with 0 < x < 50.
  3. Differentiate. A′ = 100 − 4x = 0, so x = 25.
  4. Justify. A″ = −4 < 0, so x = 25 is a maximum.
  5. Answer. x = 25 ft and y = 50 ft, giving the maximum area 1250 ft².

Worked example 2: designing a soda can

A soda can is a closed cylinder that must hold 355 cm³ (12 fl oz). (a) What radius and height use the least aluminum? (b) The top and bottom are made of thicker metal and cost twice as much per cm² as the side. What radius and height make the cheapest can?

Try it yourself first, then reveal one step at a time.

  1. Variables and constraint. Radius r and height h in cm. The volume is fixed: πr²h = 355, so h = 355/(πr²).
  2. Objective in one variable. Metal = two lids + side: S = 2πr² + 2πrh = 2πr² + 2πr·355/(πr²) = 2πr² + 710/r, for r > 0.
  3. Differentiate. S′ = 4πr − 710/r² = 0 gives r³ = 710/(4π) = 355/(2π), so r = (355/(2π))1/3 ≈ 3.84 cm.
  4. Justify and finish (a). S″ = 4π + 1420/r³ > 0 for every r > 0, so this is the minimum. h = 355/(π·3.84²) ≈ 7.67 cm: the height equals the diameter.
  5. (b) Lids cost twice as much. Cost (in side-metal units) C = 2·2πr² + 710/r = 4πr² + 710/r. C′ = 8πr − 710/r² = 0 gives r³ = 355/(4π), r ≈ 3.05 cm, and h = 355/(πr²) ≈ 12.2 cm = 4r. Costly lids push the design taller and narrower, which is the shape of the cans you see in stores.

Common mistakes

  • Not using the constraint to reduce to one variable.
  • Forgetting to check endpoints or the domain.
  • Giving the optimal x when asked for the maximum value (or the reverse).
  • Not justifying that it is a max or min.
  • Mixing units, for example using a formula with radius when the problem gives diameter.

Common setups

Perimeter fixed, maximize area: the square wins. Area fixed, minimize perimeter: the square. Volume fixed, minimize surface area of a can: height = diameter. Distance to a curve: minimize the square of the distance (the same minimum, no square root).
