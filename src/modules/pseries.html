p-series & the integral test

Compare a sum with an area. If the area under the curve is finite, so is the sum, and vice versa.

The idea

The p-series Σ 1/nᵖ converges if p > 1 and diverges if p ≤ 1. For p = 1 this is the harmonic series 1 + 1/2 + 1/3 + …, which diverges, very slowly: it takes about 12,000 terms to pass 10.

The reason is the integral test: if f is positive, continuous and decreasing, Σ f(n) and ∫₁^∞ f(x) dx either both converge or both diverge. The terms are the heights of rectangles under (or over) the curve, so the sum is squeezed between ∫₁^{N+1} f and f(1) + ∫₁^N f. The same picture bounds the tail of a convergent series: Σ_{n>N} f(n) ≤ ∫_N^∞ f.

Try this

Predict what will happen first. Then set it up and check.

  1. Set p = 2 and N = 40. How big can the sum get?

    What you should see

    Never more than 1 + ∫₁^∞ 1/x² = 2 (the sum is actually π²/6 ≈ 1.645). The rectangles are under the curve, so the sum is bounded by the area.

  2. Set p = 1. Does the sum level off?

    What you should see

    No: S_N ≥ ∫₁^{N+1} dx/x = ln(N + 1), which grows without bound. The harmonic series diverges, but slowly.

  3. Set p = 1.5 and N = 40. Compare the partial sum with the bound 1 + 1/(p − 1).

    What you should see

    S40 ≈ 2.298, safely under the bound 1 + 1/0.5 = 3. The true sum is about 2.612, so the 40-term sum is still 0.31 short: a p-series with p near 1 converges slowly.

  4. Set p = 1.1 and N = 40. Does the series converge? How far along is it?

    What you should see

    Yes, p = 1.1 > 1, but S40 is only about 3.68 while the bound is 1 + 1/0.1 = 11. When p is barely above 1 the tail is huge, so the sum is far from finished after 40 terms.

  5. Set p = 0.5 and N = 40. How does SN compare with the integral?

    What you should see

    S40 ≈ 11.27, above the integral 2(√40 − 1) ≈ 10.65, and both keep growing like 2√N without bound. Here the rectangles stay above the curve and the sum diverges.

Worked example

Use the integral test to decide Σn=1∞ 1/(n² + 1), and bound the tail after N = 10 terms of Σ 1/n².

Try it yourself first, then reveal one step at a time.

  1. Check the conditions. f(x) = 1/(x² + 1) is positive, continuous and decreasing for x ≥ 1.
  2. Integral. ∫1∞ dx/(x² + 1) = lim [arctan x]1b = π/2 − π/4 = π/4, finite.
  3. Conclude. The series converges.
  4. Tail bound. Σn>10 1/n² ≤ ∫10∞ dx/x² = 1/10.
  5. Answer. Converges; the remainder after 10 terms is at most 0.1.

Common mistakes

  • Using the integral test without checking positive, continuous, decreasing.
  • Thinking the integral equals the sum. They only share convergence (the sum is a different number).
  • Believing 1/n converges because its terms go to 0.
  • Mixing up p-series (p > 1) with the p-integral near 0 (p < 1).
  • Forgetting the first terms of the sum when estimating: S ≈ S_N + tail.

Comparing the tests

The p-series test is the integral test done once and for all for 1/nᵖ. The comparison tests (next module) use p-series as the benchmark: most rational-looking series behave like a p-series.
