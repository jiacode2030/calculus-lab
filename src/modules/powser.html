Power series: radius & interval of convergence

A power series is an infinite polynomial. It converges for x near its center, and the radius tells you how near.

The idea

A power series centered at c is Σ aₙ(x − c)ⁿ. It is a polynomial with infinitely many terms, so for each x it either converges or diverges. The set of x where it converges is an interval centered at c: the interval of convergence, with radius R (the series converges for |x − c| < R and diverges for |x − c| > R).

Find R with the ratio test on |aₙ₊₁(x − c)ⁿ⁺¹ / aₙ(x − c)ⁿ| < 1, then test the endpoints x = c ± R separately (the ratio test fails there, so use p-series, alternating, or nth-term). The radius can be 0 (only x = c) or ∞ (all x). Inside the radius, you may differentiate and integrate term by term, and the radius does not change.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose Σ xⁿ/n. At x = 1 and x = −1 what happens?

    What you should see

    At x = 1 it is the harmonic series (diverges); at x = −1 it is the alternating harmonic series (converges). So the interval is [−1, 1): the endpoints must be tested separately.

  2. Choose Σ n! xⁿ. For which x does it converge?

    What you should see

    Only at x = 0: the terms n!xⁿ blow up for any x ≠ 0 (R = 0). Compare Σ xⁿ/n!, which converges for every x (R = ∞).

Worked example

Find the radius and interval of convergence of Σn=1∞ (x − 2)ⁿ/(n·3ⁿ).

Try it yourself first, then reveal one step at a time.

  1. Ratio test. |aₙ₊₁/aₙ| = |x − 2|·n/(3(n + 1)) → |x − 2|/3.
  2. Converges when |x − 2|/3 < 1, i.e. |x − 2| < 3. So R = 3, center 2, open interval (−1, 5).
  3. Endpoint x = 5. Σ 3ⁿ/(n·3ⁿ) = Σ 1/n: harmonic, diverges.
  4. Endpoint x = −1. Σ (−3)ⁿ/(n·3ⁿ) = Σ (−1)ⁿ/n: alternating harmonic, converges.
  5. Answer. R = 3; interval of convergence [−1, 5).

Common mistakes

  • Forgetting to test the endpoints.
  • Stopping at |x − c| < R and writing the interval as closed.
  • Confusing the radius with the interval (R = 3 has length 6).
  • Using the ratio test at the endpoints (it gives L = 1: inconclusive).
  • Forgetting the center: the interval is centered at c, not at 0.

Term-by-term calculus

Inside the radius, differentiate and integrate a power series term by term, and the radius stays the same. At the endpoints convergence may change. For example, from 1/(1 − x) = Σ xⁿ (|x| < 1) you get 1/(1 − x)² = Σ n xⁿ⁻¹ and −ln(1 − x) = Σ xⁿ/n.

Check yourself: Σ xⁿ/n² has interval of convergence
