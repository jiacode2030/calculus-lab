The derivative & differentiability

The derivative is a function: at every x it gives the slope of the tangent line. Some graphs have no tangent at certain points, and those are worth knowing.

The idea

Define f′(x) = limh→0 (f(x + h) − f(x))/h. When this limit exists, f is differentiable at x and f′(x) is the slope of the tangent line there. Doing this at every x produces a new function f′, the derivative function, and its graph is built from the slopes of the original.

Differentiable means smooth: no corner, no cusp, no vertical tangent, no jump. A corner has two different one-sided slopes. A vertical tangent has an infinite slope. A discontinuity has no tangent at all. Differentiable ⇒ continuous, but not the other way: |x| is continuous at 0 and not differentiable there.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose |x| and slide x through 0. What does the slope graph do at 0?

    What you should see

    The left slope is −1 and the right slope is +1, so there is no single slope at 0: the derivative graph jumps. A corner is not differentiable.

  2. Choose ∛x and move toward 0. What happens to the slope?

    What you should see

    The slope grows without bound as x → 0 (the tangent becomes vertical), so f′(0) does not exist even though the function is continuous.

  3. Choose x² and set x = 1. Compare the slope with 2x, then try x = 2.

    What you should see

    At x = 1 the slope is 2; at x = 2 it is 4: the slope at each point is 2x, which is the derivative graph below (a straight line through the origin).

  4. Choose the step function and slide x to 0. Is it differentiable there?

    What you should see

    No: at x = 0 the graph jumps by 2 (from −1 up to 1), so there is no tangent at all. Everywhere else the pieces are lines of slope 1, so the derivative graph is the constant 1 with a gap at 0. Not continuous there, so not differentiable (differentiable ⇒ continuous).

Worked example

Use the definition to find f′(x) for f(x) = x².

Try it yourself first, then reveal one step at a time.

  1. Write the quotient. f′(x) = lim (f(x + h) − f(x))/h = lim ((x + h)² − x²)/h.
  2. Expand. (x + h)² − x² = 2xh + h².
  3. Factor out h. (2xh + h²)/h = 2x + h (for h ≠ 0).
  4. Take the limit. limh→0 (2x + h) = 2x.
  5. Answer. f′(x) = 2x. At x = 3 the slope is 6.

Common mistakes

  • Plugging h = 0 into the quotient before simplifying: it is 0/0.
  • Forgetting to expand (x + h)² as x² + 2xh + h².
  • Believing continuous means differentiable (|x| is the counterexample).
  • Writing f′(x) = limit "= 0" when the numerator goes to zero: the denominator goes to zero too.
  • Calling the derivative at a point a function. f′(a) is a number; f′(x) is a function.

Notation

f′(x), y′, dy/dx and d/dx[f(x)] all mean the same derivative. Leibniz's dy/dx reminds you it is a ratio of tiny changes (change in y over change in x). f′(a) means "evaluate the derivative function at x = a".
