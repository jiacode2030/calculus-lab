Linearization & differentials

Zoom in far enough and a curve is a line. Use the tangent line to estimate values you cannot compute by hand.

The idea

Near x = a, the curve is almost indistinguishable from its tangent line L(x) = f(a) + f′(a)(x − a). So to estimate f at a nearby point, use L instead: f(x) ≈ L(x). This is how a calculator first estimates square roots, and how physicists replace sin θ by θ for small angles.

Whether the estimate is too big or too small depends on bending. If the curve is concave down (f″ < 0) the tangent line lies above the curve: the estimate is an overestimate. If concave up (f″ > 0) the tangent lies below: an underestimate. Differentials write the same idea as dy = f′(x) dx.

Try this

Predict what will happen first. Then set it up and check.

  1. On √x with a = 1, estimate √1.2.

    What you should see

    L(x) = 1 + ½(x − 1), so L(1.2) = 1.1. The true √1.2 = 1.0954: a tiny overestimate, because √x is concave down.

  2. Slide x far from a. What happens to the error?

    What you should see

    The error grows quickly: L(4) = 2.5 but √4 = 2. A tangent line is only a good estimate close to a.

Worked example

Use a linearization to estimate √26.

Try it yourself first, then reveal one step at a time.

  1. Pick a nearby easy point. f(x) = √x, a = 25 (since √25 = 5).
  2. Slope. f′(x) = 1/(2√x), so f′(25) = 1/10.
  3. Build L. L(x) = 5 + (1/10)(x − 25).
  4. Estimate. L(26) = 5 + 0.1 = 5.1.
  5. Answer. √26 ≈ 5.1 (true value 5.0990). Overestimate, since √x is concave down.

Common mistakes

  • Choosing a not close to x. The estimate is only good near a.
  • Evaluating f′ at x instead of at a.
  • Forgetting f(a) in L(x).
  • Saying overestimate/underestimate from the sign of f′. It depends on f″ (concavity).
  • Using degrees for trig linearizations. They require radians.

Differentials

The change in y along the tangent line is dy = f′(x) dx, while the true change is Δy. For a small dx they nearly agree. This is how measurement error spreads: if the radius of a sphere is measured with a small error dr, the error in volume is about dV = 4πr² dr.
