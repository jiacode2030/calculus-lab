L'Hôpital's rule

If a limit of a ratio is 0/0 or ∞/∞, you can differentiate the top and bottom separately and try again.

The idea

When both f and g go to 0 at a, the ratio f/g depends on how fast each goes to 0. Near a, f ≈ f′(a)(x − a) and g ≈ g′(a)(x − a), so their ratio is about f′(a)/g′(a): the ratio of their rates. That is L'Hôpital's rule: lim f/g = lim f′/g′, if the left side is 0/0 or ∞/∞ and the right side exists.

Check the form first. Never apply the rule to something that is not 0/0 or ∞/∞. Other indeterminate forms (0·∞, ∞ − ∞, 1∞) must be rewritten into a ratio first. You differentiate top and bottom separately: this is not the quotient rule.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose (eˣ − 1)/x and zoom in. Compare the two ratios.

    What you should see

    Both head to 1. The ratio of derivatives, eˣ/1, is already 1 at x = 0, so L'Hôpital gives the limit in one line.

  2. Choose x²/eˣ and widen the window. Which grows faster, top or bottom?

    What you should see

    The exponential wins: the ratio heads to 0. Applying the rule twice: x²/eˣ → 2x/eˣ → 2/eˣ → 0.

Worked example

Find limx→0 (1 − cos x)/x².

Try it yourself first, then reveal one step at a time.

  1. Check the form. 1 − cos 0 = 0 and 0² = 0: the form 0/0, so the rule applies.
  2. Differentiate top and bottom. (sin x)/(2x).
  3. Check again. Still 0/0 at x = 0, so apply the rule once more.
  4. Differentiate again. (cos x)/2, which at x = 0 is 1/2.
  5. Answer. The limit is 1/2.

Common mistakes

  • Using the quotient rule on f/g. Differentiate the top and bottom separately.
  • Applying the rule when the form is not 0/0 or ∞/∞ (for example 1/0 or 0/5).
  • Stopping after one step when the form is still 0/0.
  • Applying it to 0·∞ or ∞ − ∞ directly. Rewrite as a quotient first.
  • Concluding the original limit does not exist because f′/g′ oscillates: then the rule gives no information.

Growth rates

L'Hôpital settles a hierarchy: as x → ∞, ln x grows slower than any power of x, which grows slower than any exponential. So (ln x)/x → 0 and xn/ex → 0 for every n.
