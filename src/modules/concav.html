Concavity & the second derivative test

Concavity is the bend of a curve: bending up like a cup, or down like a frown. It is the sign of f″.

The idea

If f″ > 0 the slope f′ is increasing: the graph is concave up (holds water). If f″ < 0 the slope is decreasing: concave down. A point of inflection is where the concavity changes, so f″ changes sign (f″ = 0 or DNE there, but that alone is not enough).

Second derivative test: at a critical point c (f′(c) = 0), if f″(c) > 0 the curve bends up there: local minimum. If f″(c) < 0: local maximum. If f″(c) = 0 the test says nothing: go back to the first derivative test.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose x³ − 3x and slide through 0. What happens to the tangent line and to f″?

    What you should see

    f″ = 6x changes sign at 0: concave down to the left, concave up to the right. The tangent line crosses from above the curve to below it: an inflection point.

  2. Choose x⁴ and put x at 0. f″(0) = 0. Is there an inflection point?

    What you should see

    No. f″ = 12x² is 0 at x = 0 but positive on both sides, so concavity does not change. f″ = 0 is not enough; the test fails here, yet x = 0 is a minimum.

  3. Choose x⁴ − 2x² with x = 0. Use the second derivative test, then find the inflection points.

    What you should see

    f′(0) = 0 and f″(0) = −4 < 0, so x = 0 is a local maximum. f″ = 12x² − 4 = 0 at x = ±1/√3 ≈ ±0.577, and it changes sign at both, so those are inflection points. Between them the curve is concave down.

  4. Choose x³ − 3x with x = 1. What does the second derivative test say?

    What you should see

    f′(1) = 0 and f″(1) = 6 > 0: concave up at a flat point, so x = 1 is a local minimum, f(1) = −2. The tangent is horizontal and sits under the curve.

  5. Choose sin x with x = 1.5. Is the curve bending up or down, and why does that match the picture?

    What you should see

    f″ = −sin x ≈ −0.997 < 0: concave down. Near the top of the wave (x = π/2 ≈ 1.57) the curve bends down like a frown, and the tangent lies above it.

Worked example

For f(x) = x³ − 6x² + 9x, find the local extrema using the second derivative test, and the inflection point.

Try it yourself first, then reveal one step at a time.

  1. f′. f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3), so critical points x = 1 and x = 3.
  2. f″. f″(x) = 6x − 12.
  3. Test. f″(1) = −6 < 0: local maximum f(1) = 4. f″(3) = 6 > 0: local minimum f(3) = 0.
  4. Inflection. f″ = 0 at x = 2, and f″ changes from negative to positive there. The inflection point is (2, 2).

Common mistakes

  • Saying f″ = 0 means an inflection point. The sign must change.
  • Using f″ to find concavity but writing the answer in terms of f′ (or the reverse).
  • Applying the second derivative test where f″ = 0, and concluding "neither".
  • Confusing concave up with increasing. A curve can be decreasing and concave up.
  • Forgetting that concavity changes can happen where f″ does not exist.

Two tests, one picture

At a critical point the first derivative test looks at the sign of f′ on each side; the second derivative test looks at the bend at the point. Use whichever is quicker; if the second derivative test is inconclusive (f″ = 0), fall back on the first.
