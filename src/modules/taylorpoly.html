Taylor polynomials & Lagrange error

Approximate any smooth function near a point by a polynomial built from its derivatives. And know how big the error can be.

The idea

The Taylor polynomial of degree n centered at a is P_n(x) = Σ_{k=0}^{n} f⁽ᵏ⁾(a)(x − a)ᵏ/k!. It matches f and its first n derivatives at a, so it hugs f near a. Degree 1 is the tangent line; degree 2 adds the bend. When a = 0 it is called a Maclaurin polynomial.

The Lagrange error bound says how far off P_n can be: |f(x) − P_n(x)| ≤ M|x − a|ⁿ⁺¹/(n + 1)!, where M is the maximum of |f⁽ⁿ⁺¹⁾| between a and x. Higher degree and a closer x make the bound tiny. This is how a computer can find sin 0.5 or e0.5 using only addition and multiplication: with enough terms of a polynomial.

Try this

Predict what will happen first. Then set it up and check.

  1. On sin x, raise the degree from 1 to 7. What changes?

    What you should see

    The polynomial hugs sin x over a wider and wider interval around 0. At x = 2, P₇(2) ≈ 0.9079 while sin 2 ≈ 0.9093: the error is about 0.0014, and degree 9 cuts it to under 0.0001.

  2. Choose ln(1+x) and move the probe to x = 1.5. What happens as n grows?

    What you should see

    The error does not shrink: ln(1 + x) has a Taylor series only for −1 < x ≤ 1. Outside that interval the polynomials get worse, not better.

  3. Choose eˣ with n = 3 at x = 1. Compare the actual error with the Lagrange bound.

    What you should see

    P₃(1) = 1 + 1 + 1/2 + 1/6 ≈ 2.6667 against e ≈ 2.7183, an error of about 0.052. The bound uses M = e¹: e/4! ≈ 0.113. The bound is a guarantee, not an estimate, so it is usually bigger than the real error.

  4. Choose cos x and put the probe far out at x = 2.8. Compare degree 2 with degree 10.

    What you should see

    Degree 2 gives −2.92 against cos 2.8 ≈ −0.942, way off. Degree 10 gives about −0.9427, an error near 0.0005. Far from the center you need many more terms.

Worked example

Find the degree-3 Maclaurin polynomial of f(x) = ex and use the Lagrange bound to bound the error at x = 0.5.

Try it yourself first, then reveal one step at a time.

  1. Derivatives at 0. f⁽ᵏ⁾(0) = 1 for every k.
  2. Polynomial. P₃(x) = 1 + x + x²/2 + x³/6.
  3. Estimate. P₃(0.5) = 1 + 0.5 + 0.125 + 0.0208 = 1.6458 (true e0.5 = 1.6487).
  4. Bound. f⁗ = eˣ ≤ e0.5 < 1.7 on [0, 0.5]. |error| ≤ 1.7(0.5)⁴/4! = 1.7(0.0625)/24 ≈ 0.0044.
  5. Answer. P₃ = 1 + x + x²/2 + x³/6; error at 0.5 is at most 0.0044 (actual 0.0029).

Worked example 2: how a computer finds sin 0.5

A processor can only add, subtract, multiply and divide, so it cannot "look up" sin 0.5. (a) Estimate sin 0.5 with the degree-3 Maclaurin polynomial. (b) Improve it with degree 5. (c) Use the Lagrange bound to guarantee the accuracy of (b). (d) Why is it enough to handle small x?

Try it yourself first, then reveal one step at a time.

  1. The polynomial. The derivatives of sin at 0 cycle 0, 1, 0, −1, so only odd powers appear, with alternating signs: sin x ≈ x − x³/3! + x⁵/5! − …
  2. (a) Degree 3. P₃(0.5) = 0.5 − 0.125/6 ≈ 0.479167. The true value is sin 0.5 = 0.4794255…, so the error is about 0.00026.
  3. (b) Degree 5. Add 0.5⁵/120 = 0.03125/120 ≈ 0.00026: P₅(0.5) ≈ 0.479427, now off by only about 0.0000015.
  4. (c) Guarantee. sin has no x⁶ term, so P₅ = P₆ and we may use n = 6. Every derivative of sin is at most 1 in size, so M = 1 and |error| ≤ 0.5⁷/7! ≈ 1.55 × 10⁻⁶. The actual error is 1.54 × 10⁻⁶, just under the bound.
  5. (d) Only small x. sin repeats every 2π, and identities such as sin(π − x) = sin x and sin x = cos(π/2 − x) turn any angle into the sine or cosine of an angle in [0, π/4] (cosine has its own polynomial, 1 − x²/2! + x⁴/4! − …). There (π/4)¹³/13! ≈ 7 × 10⁻¹², so a degree-12 polynomial is accurate to about 11 decimal places. Computer math libraries use this idea with a slightly tuned polynomial; many handheld calculators use a different method called CORDIC.

Common mistakes

  • Forgetting the k! in the denominators.
  • Using the (n)th derivative instead of the (n + 1)th in the Lagrange bound.
  • Using a polynomial far from its center and trusting it.
  • Mixing up the degree n and the number of terms (n + 1 terms for degree n).
  • Forgetting to evaluate the derivatives at the center a, not at x.

Reading coefficients

The coefficient of (x − a)ᵏ is f⁽ᵏ⁾(a)/k!. So if P₃(x) = 2 + 3x − 4x² + 10x³, then f(0) = 2, f′(0) = 3, f″(0) = 2!·(−4) = −8, f‴(0) = 3!·10 = 60.
