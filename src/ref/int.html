Fundamental Theorem

d/dx ∫ax f(t) dt = f(x)
part 1
d/dx ∫ag(x) f(t) dt = f(g(x)) · g′(x)
with the chain rule
∫ab f(x) dx = F(b) − F(a)
part 2, F′ = f
∫ab f′(x) dx = f(b) − f(a)

Approximating

Left / right: Δx [y0 + … + yn−1] or [y1 + … + yn]
Δx = (b−a)/n
Trapezoid: (Δx/2)(y0 + 2y1 + … + 2yn−1 + yn)
Midpoint: Δx · Σ f(midpoints)
