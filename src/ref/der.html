Definition

f′(x) = limh→0 [f(x+h) − f(x)] / h
slope of the tangent
f′(a) = limx→a [f(x) − f(a)] / (x − a)
same, at one point

Rules

d/dx [c] = 0
constant
d/dx [xn] = n xn−1
power rule
(cf)′ = c f′ , (f ± g)′ = f′ ± g′
linearity
(fg)′ = f′g + fg′
product
(f/g)′ = (f′g − fg′) / g²
quotient
d/dx f(g(x)) = f′(g(x)) · g′(x)
chain

Trig

(sin x)′ = cos x
(cos x)′ = −sin x
(tan x)′ = sec²x
(cot x)′ = −csc²x
(sec x)′ = sec x tan x
(csc x)′ = −csc x cot x

Exponential and log

(ex)′ = ex
(ax)′ = ax ln a
(ln x)′ = 1/x
x > 0
(loga x)′ = 1 / (x ln a)

Inverse functions

(f−1)′(a) = 1 / f′(f−1(a))
where f′ ≠ 0
(arcsin x)′ = 1/√(1−x²)
(arccos x)′ = −1/√(1−x²)
(arctan x)′ = 1/(1+x²)

Applications

linearization

Mean Value Theorem
lim f/g = lim f′/g′
L′Hôpital, for 0/0 or ∞/∞
v = x′ , a = v′ = x″ , speed = |v|
motion on a line
f′ > 0 increasing · f″ > 0 concave up
signs

BC: parametric, polar, vector

dy/dx = (dy/dt) / (dx/dt)
parametric slope
d²y/dx² = [d/dt(dy/dx)] / (dx/dt)
concavity
velocity = ⟨x′(t), y′(t)⟩
vector motion

polar to rectangular

polar slope
