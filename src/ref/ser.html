Limits

limx→a f(x) exists iff left = right
one-sided limits agree
continuous at a: lim f(x) = f(a)
defined, limit exists, equal
limx→0 sin x / x = 1
limx→0 (1 − cos x) / x = 0
limx→0 (ex − 1) / x = 1
IVT: f continuous on [a,b] takes every value between f(a) and f(b)
EVT: continuous on [a,b] has an absolute max and min

Series tests

geometric Σ arn = a/(1 − r)
only if |r| < 1
nth-term: if an ↛ 0, the series diverges
cannot prove convergence
p-series Σ 1/np converges iff p > 1
p = 1: harmonic, diverges
integral test: Σ an and ∫ f behave alike
f positive, decreasing
comparison: 0 ≤ an ≤ bn
big converges ⇒ small converges
limit comparison: lim an/bn = L, 0 < L < ∞
same behavior
alternating: terms shrink to 0
converges; error ≤ first omitted term
ratio: L = lim |an+1/an|
< 1 converges · > 1 diverges · = 1 no info
absolute convergence ⇒ convergence
conditional: converges, but Σ|an| diverges
